ALUMNI — STORIES 1.1 / PROPUESTA C PREMIUM

OBJETIVO
Esta versión ya no es un retoque superficial. Cambia el visor real de Stories para que se parezca claramente a la Propuesta C elegida: una experiencia centrada en conversación, con tarjeta blanca protagonista e interacción rápida.

CAMBIOS VISUALES
- Tarjeta blanca premium sobre la historia.
- Título de conversación contextual.
- Respuestas rápidas reales: Inspirador / Me sirve / Conversemos.
- Las respuestas rápidas rellenan el reply real; no son una encuesta falsa.
- Métricas dentro de la tarjeta para la historia propia.
- Header de vidrio más limpio.
- Barra de respuesta completamente rediseñada.
- Reacción integrada en el nuevo lenguaje visual.
- Mejor adaptación móvil.
- Animación de entrada y reduced-motion.

ARCHIVOS QUE MODIFICA
- src/app/feed/page.tsx
- src/components/stories/StoryViewer.tsx

ARCHIVO NUEVO
- src/app/feed/stories-visual-1-1.css

IMPORTANTE
El instalador ejecuta git add de los 3 archivos anteriores, incluyendo el CSS nuevo. Esto evita el problema de Vercel ocurrido en Stories 1.0, donde un archivo nuevo no entró con git commit -am.

USO
1. Copia este ZIP dentro de alumni-web y extráelo.
2. Desde alumni-web ejecuta:
   node APLICAR_STORIES_1_1_C_PREMIUM.js
   npm run test
   npm run typecheck
   npm run build
3. Si todo pasa:
   git commit -m "Stories 1.1 - Proposal C premium interactive viewer"
   git push

No uses git commit -am para esta fase: hay un CSS nuevo y el instalador ya lo deja staged.
