- Configuración = Lista clásica
- perfil arriba
- Cuenta

EL TRABAJO ES ADENTRO.

1. APARIENCIA
Antes:
- radio visual antiguo
- clases Dark-only
- card dentro de panel

Ahora:
- lista limpia
- Claro / Oscuro
- preview pequeño
- check Accent
- descripción breve
- Dark/Light real

2. PRIVACIDAD
- panel plano
- switch consistente
- solicitudes de seguimiento
- modal móvil limpio
- sin cards anidadas

3. SEGURIDAD
Conserva toda la lógica:
- correo
- recuperación
- cambio de contraseña
- bloqueados
- silenciados
- exportar datos
- legales
- sesión
- eliminar cuenta

Visual:
- secciones planas
- separadores
- sin fondos Dark-only
- modales consistentes

4. EDITAR PERFIL
- header compacto
- guardar como acción Accent
- portada/avatar más limpios
- secciones con jerarquía
- filas más consistentes
- pickers de universidad/carrera/país rediseñados
- mobile-first

5. GUARDADOS
- header y separación más limpios
- integrado a Settings
- no se cambia su lógica

6. DEEP SETTINGS / SPOTIFY
Las rutas/secciones antiguas que aún se pueden abrir por URL
quedan protegidas para Dark/Light.
