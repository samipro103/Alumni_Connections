ALUMNI FEEDBACK 2.1 — EDITORIAL MODERNO

DISEÑO ELEGIDO
Opción 4 del tablero, adaptada a ALUMNI.

IMPORTANTE
NO cambia el hub principal de Feedback 2.0.
La pantalla principal sigue siendo la lista limpia:

- Centro de ayuda
- Reportar un problema
- Sugerir una mejora
- Estado de la app
- Contactar soporte
- Términos y privacidad

ESTE PARCHE CAMBIA "ADENTRO ADENTRO":
cuando el usuario entra a escribir un feedback.

NUEVO FORMULARIO

1. HERO EDITORIAL
Título y contexto adaptados según:
- Problema
- Idea
- Soporte

2. ASUNTO
Campo limpio, contador de caracteres.

3. ÁREA GRANDE DE ESCRITURA
Hasta 1000 caracteres.
Mucho más cómoda para teléfono.

4. ADJUNTAR CAPTURA
Fila discreta.
Hasta 4 imágenes de máximo 8 MB.

5. PRIORIDAD
Queda disponible, pero visualmente secundaria.

6. DETALLES TÉCNICOS
En reportes de problema:
- Qué esperabas
- Pasos para repetirlo

quedan ocultos bajo:
"Añadir detalles técnicos"

Así no ensucian la pantalla principal.

7. ENVÍO
Botón ancho:
- Enviar reporte
- Enviar sugerencia
- Enviar mensaje

según corresponda.

BACKEND
NO CAMBIA.
Se conserva:
- feedback_reports
- bucket feedback
- type
- priority
- title
- description
- expected_behavior
- steps_to_reproduce
- source_path
- platform
- app_version
- attachments

DARK / LIGHT
100% tokens ALUMNI.

MOBILE-FIRST
360–430 px.

REQUISITO
Feedback 2.0 debe estar aplicado primero.

EJECUCIÓN

node .\aplicar_alumni_feedback_2_1_editorial_moderno.js
npm run build

SI BUILD PASA

git add .
git commit -m "Feedback 2.1 - editorial modern form"
git push origin main
