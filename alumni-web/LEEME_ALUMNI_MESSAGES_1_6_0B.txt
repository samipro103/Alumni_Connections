ALUMNI MESSAGES 1.6.0B — CRLF FIX

El parche 1.6.0 anterior NO guardó cambios porque se detuvo antes del guardado.

CAUSA
Windows usa CRLF en algunos archivos y el parche comparaba varios bloques
multilínea con LF. Por eso encontró líneas simples, pero falló en el subtítulo.

1.6.0B:
- normaliza CRLF/LF antes de aplicar cambios;
- usa un matcher tolerante para el subtítulo;
- mantiene exactamente la selección aprobada:
  * Afuera: Opción 1 — Inbox limpio
  * Adentro: Opción 2 — Chat enfocado
- sin llamadas;
- mobile-first;
- claro/oscuro;
- conserva toda la lógica existente;
- valida Inbox, chat directo y chat grupal antes de guardar.

EJECUTAR DESDE alumni-web:

node .\aplicar_alumni_messages_1_6_0b_inbox1_chat2_crlf_fix.js
npm run build
