ALUMNI — MOTION SYSTEM 1.0

NUEVA REGLA DE PRODUCTO

Motion es parte obligatoria del lenguaje visual de ALUMNI.

ESTE PARCHE AGREGA

- Transición global en todas las rutas dentro de AppShell.
- Entrada sutil:
  opacity
  translateY
  scale
- Microtransiciones globales en:
  botones
  links
  inputs
  textarea
  select
  elementos presionables
- Tokens globales de velocidad/easing.
- Respeta prefers-reduced-motion.

NUEVOS COMPONENTES

src/components/motion/AlumniMotion.tsx

Incluye:

AlumniRouteMotion
MotionReveal
MotionCard
MotionPressable

REGLA PARA TODO LO NUEVO

Toda pantalla nueva debe usar motion.
Toda sección importante debe entrar con reveal.
Toda card interactiva debe tener feedback de motion.
Todo botón/acción debe responder visualmente.
Modales y overlays deben animar entrada/salida.
Listas nuevas deben usar stagger cuando tenga sentido.
Carga/success/error deben tener transición.
Nada debe sentirse estático si existe una interacción.

IMPORTANTE

Motion NO significa animar exageradamente.
Debe sentirse:
rápido
natural
premium
intencional
