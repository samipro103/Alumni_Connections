IMPORTANTE:
Actualmente no había ningún admin registrado en admin_permissions.
Por eso se incluye un bootstrap local de propietario.

1) Aplicar parche:
node .\aplicar_alumni_admin_control_center_1_0.js

2) Build:
npm run build

3) Crear tu cuenta propietaria admin usando TU username real:
node .\scripts\admin\bootstrap_alumni_owner_admin.js --username=TU_USUARIO

Ejemplo:
node .\scripts\admin\bootstrap_alumni_owner_admin.js --username=samipro

NO compartas SUPABASE_SECRET_KEY.
El script la lee de .env.local.

4) Si build pasa:
git add .
git commit -m "Add Alumni admin control center"
git push origin main

5) Entrá con tu cuenta a:
https://alumnisv.com/admin

CONTROL:
- Verificar/revocar usuario
- Restringir creación de posts/comentarios/mensajes
- Suspender cuenta
- Restaurar cuenta
- Dar permisos a moderadores
- Moderar posts
- Moderar comentarios
- Revisar reportes
- Ver historial de acciones

NOTA:
La verificación NO se puede autootorgar desde el cliente.
Las acciones sensibles están protegidas por RPC/permisos en Supabase.
