PARTE B - LIMPIEZA DE HISTORIAS
-------------------------------
La función está en:

supabase/functions/cleanup-expired-stories/index.ts

Hace esto:
1. Busca historias con expires_at < now()
2. Borra el archivo real del bucket "stories"
3. Borra el registro de stories
4. story_views/story_likes se eliminan por CASCADE

Así ya no dejamos basura en Storage.


FORMA MÁS FÁCIL DE INSTALARLA
-----------------------------
Puedes hacerlo TODO desde el Dashboard de Supabase.

1. Supabase > Edge Functions
2. Deploy a new function
3. Via Editor
4. Nombre:
   cleanup-expired-stories
5. Sustituye el código del editor por el contenido de:
   supabase/functions/cleanup-expired-stories/index.ts
6. Deploy function


PROGRAMARLA AUTOMÁTICAMENTE
---------------------------
Después:

Supabase > Integrations / Cron
(o Cron / Jobs, según cómo aparezca en tu Dashboard)

Create job

Nombre:
cleanup-expired-stories-hourly

Frecuencia:
cada hora

Selecciona:
Supabase Edge Function

Función:
cleanup-expired-stories

Guarda.

Con eso cada hora Alumni limpia historias expiradas físicamente.


IMPORTANTE DE SEGURIDAD
-----------------------
No copies ninguna Secret Key dentro del código.

La Edge Function utiliza automáticamente las variables server-side de Supabase:
- SUPABASE_URL
- SUPABASE_SECRET_KEYS

La Secret Key nunca se manda al navegador.
