ALUMNI 2.3.3 — PASSPORT PROFILE + FEED FIX
================================================

ACLARACIÓN APLICADA
===================
Pasaporte se QUITA de los 3 puntos / Más.
Ajustes SE QUEDA.

PERFIL
======
Ahora aparece una carta visual tipo pasaporte:

[ PASAPORTE ]
Pasaporte Alumni
Próximo destino: 🇯🇵 Japón
+ Añadir país

No se convierte todo el perfil en cards.
La única pieza con forma de carta es el objeto temático
del pasaporte que el usuario pidió.

AÑADIR PAÍSES DESDE PERFIL
===========================
El botón + Añadir país del perfil abre directamente el creador
existente del Pasaporte.

No rediseña /passport.
Usa /passport?add=1 y abre el creador automáticamente.

FEED
====
Producción tiene publicaciones reales.

Se cambia la carga para:
1. leer posts
2. leer autores
3. leer likes

por separado.

Así un fallo en una relación ya no deja el feed completo vacío.

Además, si falla la hidratación de una foto/video:
las publicaciones de texto continúan apareciendo.

SQL
===
NO requiere SQL.
