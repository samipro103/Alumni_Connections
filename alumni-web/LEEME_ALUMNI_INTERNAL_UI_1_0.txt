ALUMNI INTERNAL UI 1.0 — DARK / LIGHT CLEAN SYSTEM

OBJETIVO
Que ALUMNI no solo se vea profesional "por fuera".

Este bloque limpia los interiores de las funciones:
- listas;
- pantallas de detalle;
- formularios;
- modales;
- editores;
- inputs;
- botones;
- preferencias;
- estados vacíos;
- navegación secundaria.

PRINCIPIO
La app tiene SOLO DOS TEMAS:
- Dark
- Light

Se eliminan referencias visuales residuales a:
- Pride
- Chill
- Midnight
- Emerald
- Executive

NOTA
Los estilos "Aurora / Sunset / Night / Coast / Stamp"
del PASAPORTE son estilos fotográficos del contenido del pasaporte,
NO temas globales de la app, y se conservan.

COBERTURA

1. COMUNIDADES
- lista;
- búsqueda;
- tabs;
- crear comunidad;
- campos;
- opciones;
- detalle;
- composer;
- publicaciones internas.

2. EVENTOS
- lista;
- búsqueda;
- tabs;
- crear evento;
- inputs;
- opciones;
- detalle;
- RSVP;
- asistentes.

3. MENSAJES
Se preserva exactamente la decisión de producto:
- Inbox = Opción 1 limpio
- Chat = Opción 2 enfocado
- sin llamadas

Solo se refuerza consistencia de tema/focus/interiores.

4. NOTIFICACIONES
- actividad;
- tabs;
- preferencias;
- bottom sheet.

5. CONFIGURACIÓN
Se conserva:
- Opción 1 Lista clásica

Se limpia:
- paneles internos;
- editor de perfil;
- inputs;
- detalles.

6. FEEDBACK / AYUDA
Es una de las pantallas con más estilos antiguos Dark-only.
Este parche la convierte a Dark/Light real.

7. PASAPORTE
- contenido sigue siendo visual/colorido;
- chrome y formularios obedecen Dark/Light;
- en móvil los países pasan a carrusel horizontal;
- álbum móvil más compacto.

8. BUSCAR
Se conserva Opción 4.
Solo se refuerza seguridad temática.

9. SHELL / SIDEBARS
Se eliminan colores Dark-only de las barras laterales.

10. TEMA
layout.tsx deja de aceptar temas antiguos.
ThemeProvider sincroniza theme-color del navegador/PWA.

NO TOCA
- Supabase;
- RLS;
- tablas;
- lógica de mensajes;
- lógica de eventos;
- lógica de comunidades;
- lógica de publicaciones;
- Media Rendering;
- diseño principal del Perfil;
- Stories ocultas;
- permisos.

ARCHIVO NUEVO
src/app/interior-ui-1-0.css

EJECUCIÓN
Desde alumni-web:

node .\aplicar_alumni_internal_ui_1_0_dark_light_clean.js
npm run build

SI BUILD PASA:

git add .
git commit -m "Internal UI 1.0 - clean Dark Light app surfaces"
git push origin main

PRUEBA VISUAL RECOMENDADA EN TELÉFONO
Revisar en Dark y luego en Light:

- Comunidades > Crear > abrir una comunidad
- Eventos > Crear > abrir un evento > RSVP
- Mensajes > abrir conversación
- Notificaciones > Preferencias
- Configuración > Cuenta / Privacidad / Apariencia / Seguridad
- Editar perfil
- Ayuda / Feedback
- Pasaporte > Añadir país > Agregar foto
- Buscar > filtros

No debería aparecer ningún panel blanco dentro de Dark,
ni ningún panel oscuro heredado dentro de Light.
