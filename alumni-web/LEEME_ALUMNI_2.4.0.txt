ALUMNI 2.4.0 — EMAIL 2FA
=========================

FLUJO
=====
Correo + contraseña
        ↓
Alumni valida contraseña
        ↓
Alumni envía código de 6 dígitos al correo registrado
        ↓
Usuario escribe código
        ↓
Alumni entrega la sesión
        ↓
Entra al feed

SEGURIDAD
=========
- No es magic link.
- La sesión NO llega al navegador antes del código.
- Código de 6 dígitos.
- 10 minutos de vigencia.
- Máximo 5 intentos.
- Reenvío limitado.
- Tokens pendientes cifrados en backend.
- Sesiones antiguas sin verificación quedan bloqueadas.
- Sesiones TOTP ya abiertas se mantienen solo como transición.

==================

- fondo oscuro Alumni
- Alumni. arriba
- "Código de seguridad"
- código grande: 482 731
- caja alta y limpia
- expiración 10 minutos
- aviso de no compartir el código

BACKEND
=======
YA APLICADO EN PRODUCCIÓN.
Edge Function activa: email-2fa

NO ejecutar SQL.

FALTA CONFIGURAR EL REMITENTE
=============================
Antes del push del frontend debes configurar en Supabase Edge Function Secrets:

RESEND_API_KEY
ALUMNI_EMAIL_FROM

Ejemplo:
RESEND_API_KEY = re_xxxxxxxxxx
ALUMNI_EMAIL_FROM = Alumni <seguridad@tudominio.com>

El dominio debe estar verificado en Resend.

================
APLICAR_ALUMNI_2.4.0.bat
npm run build

NO HAGAS PUSH TODAVÍA si el remitente no está configurado.
