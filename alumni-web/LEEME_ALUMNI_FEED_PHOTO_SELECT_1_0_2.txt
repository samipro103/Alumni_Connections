ALUMNI FEED PHOTO SELECT 1.0.2 — NULL STAGE HOTFIX

ERROR CORREGIDO

src/components/feed/ImageCropEditor.tsx

Type error:
'node' is possibly 'null'

CAUSA

Dentro del useEffect se hacía:

const node = stageRef.current;
if (!node) return;

pero luego node se usaba dentro de una función interna measure().
TypeScript no conserva ese narrowing de forma segura dentro del closure.

SOLUCIÓN

Se crea una referencia estable:

const stage = node;

y measure() usa:

stage.getBoundingClientRect()

También ResizeObserver observa stage.

Este hotfix solo revisa copias activas potenciales:
