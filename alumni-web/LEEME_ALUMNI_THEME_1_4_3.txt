ALUMNI THEME 1.4.3 — DARK/LIGHT FEED + STORIES

OBJETIVO
Dejar oficialmente solo DOS temas en ALUMNI:
- Oscuro
- Claro

CAMBIOS
1. ThemeProvider deja de ofrecer Pride.
2. Los temas legacy (Chill, Pride, Midnight, Emerald y Executive) se eliminan del bloque principal de variables CSS.
3. Feed queda reforzado para superficies, texto, bordes, composer y media en ambos temas.
4. Stories Rail queda reforzado para ambos temas.
5. StoryComposer deja de estar bloqueado en Dark y ahora respeta el tema elegido.
6. El visor de fotos/videos de Stories permanece oscuro intencionalmente para que progreso, botones y controles mantengan contraste sobre cualquier foto o video.
7. El color nativo/status bar queda limitado a Dark/Light.

ARCHIVOS MODIFICADOS
- src/components/theme/ThemeProvider.tsx
- src/lib/nativeExperience.ts
- src/app/globals.css
- src/components/stories/StoryComposer.tsx

IMPORTANTE
Este parche es independiente del parche Stories 1.3.4.
Si ya aplicaste 1.3.4 localmente, este script está preparado para trabajar encima de esa versión.

EJECUTAR DESDE alumni-web:

node .\aplicar_alumni_theme_1_4_3_dark_light_feed_stories.js
npm run build

SI EL BUILD TERMINA BIEN:

git add .
git commit -m "Theme 1.4.3 - dark light feed and stories"
git push origin main
