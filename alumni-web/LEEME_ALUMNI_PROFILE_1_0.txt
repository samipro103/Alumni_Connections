
ALUMNI PROFILE 1.0 — OPCIÓN 3 / ACTIVITY FOCUS

DISEÑO APROBADO
Vamos con la Opción 3 full:
- perfil centrado en la actividad;
- header/hero limpio;
- identidad clara;
- métricas visibles;
- pestañas priorizadas para contenido;
- enfoque principal en Posts / Guardados / Actividad.

ENFOQUE
- Mobile-first real: 360 / 390 / 412 / 430 px.
- Desktop conserva el mismo lenguaje móvil y solo se centra.
- Claro y Oscuro compatibles.

QUÉ HACE EL PARCHE
- detecta automáticamente la ruta principal del perfil;
- agrega una hoja CSS específica para el perfil;
- cambia el copy principal hacia “Posts / Actividad / Resumen” cuando existe;
- limpia menciones residuales de Stories;
- aplica una capa visual activity-first sin borrar la lógica actual del perfil.

IMPORTANTE
Este parche está hecho para ser conservador:
- no destruye la lógica del perfil;
- no toca backend;
- no toca feed, mensajes o settings;
- solo cambia la presentación del área de perfil.
