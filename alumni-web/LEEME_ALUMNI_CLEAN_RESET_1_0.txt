ALUMNI — CLEAN RESET 1.0

OBJETIVO
Quitar las cajas que agregó Visual Pass 2.0 y volver al
lenguaje limpio/plano que ya tenían las pantallas.

SE LIMPIA

FEED
- Composer sin caja externa añadida.
- Tabs sin superficie/caja extra.
- Sin sombra del Visual Pass.

MENSAJES
- Header nuevamente plano.
- Lista nuevamente plana.
- Se conserva el diseño Inbox limpio original.

BUSCAR

- Se elimina la caja/hero añadida.
- Se conserva el buscador y categorías originales.

PERFIL
- Se eliminan bordes/sombra extras añadidos por Visual Pass.
- Se conserva el diseño original del perfil y su avatar.

EVENTOS

- Header vuelve a estar alineado.

- Mismo arreglo que Eventos.
- Texto nuevamente alineado con el contenido.

FEEDBACK 4.0
Se reemplaza toda la interfaz anterior por:
- botón volver

NO muestra:
- tipo de problema
- prioridad
- comportamiento esperado
- pasos
- centro de ayuda
- estado
- legal
- cards explicativas

Internamente sigue guardando la información necesaria para que
el sistema actual de feedback continúe funcionando.

Se conserva motion donde corresponde.
